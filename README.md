# Playground CSS

This project is a small single-page CSS playground and personal portfolio landing page built with HTML and custom CSS, using Tailwind via CDN for styling utilities.

It includes:
- a hero section with a bold branded title and animated scroll movement
- a sticky navigation bar with theme and style toggles
- a project showcase area for portfolio items
- an About section with placeholder content
- a creative contact CTA with animated letter effects and scroll-driven motion
- dark/light mode switching and a plain-style mode for testing stripped-down layouts

Open the page in a browser to explore the visual effects and experiment with the styling.
