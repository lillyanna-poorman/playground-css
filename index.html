Design practice through Code

Playground CSS is simple a personal project where I experiement the fundimental concepts of CSS, supported by HTML, Tailwind, and JavaScript. It gives me a space to explore design concepts and user interactions such as:

  • Layouts and typography
  • Color Systems and theme switching
  • Responsive Design
  • Scroll-driven animation
  • Interactive UI components

Experimenting with these elements allow me to prototype ideas that can be difficult to replicate in Figma or other design tools. By building and testing interactions directly in code, I can explore UX/UI principles in a more realistic envirement while becoming increasingly comfortable working with source code.

This experience helps me:

  • Provide frontend support for developers focused on backend systems or complex logic
  • Communicate more effectively with cross-functional teams by understanding development terminology and workflows
  • Create designs that account for tecnical constraints and impementation realities

Ultimately, this project helps me become a more effective UX designer, collaborator, and problem solver by bridging the gap between design and development.
